## 2. 画面要素

### 2.1 ナビゲーションバー（全画面共通）

ログイン状態およびロールに応じて表示を切り替える。

* ログイン中:
    * 獲得ポイント表示
    * 広告非表示ステータス（残り時間）※実装予定
    * 管理メニュー（管理者のみ）
    * ユーザーメニュー（マイページ、ログアウト）
* 未ログイン:
    * ログインリンク
    * 新規登録リンク

| ID   | 機能名      | 関連画面 | 概要          | 認証 | 権限       |
| ---- | -------- | ---- | ----------- | -- | -------- |
