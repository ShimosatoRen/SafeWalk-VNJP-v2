## 2. テーブル定義書

### 2.1 ER図

```mermaid
erDiagram

    AspNetUsers ||--o{ DangerSpots : creates

    AspNetUsers {
        string Id PK
        int Points
        datetime AdFreeUntil
        datetime RegistrationDate
    }

    DangerSpots {
        bigint Id PK
        string Title
        string Description
        string Category
        decimal Latitude
        decimal Longitude
        string UserId FK
        int Status
        datetime CreatedAt
        datetime UpdatedAt
    }
```

### 2.2 テーブル定義（主要追加カラムのみ）

#### 2.2.1 AspNetUsers

| カラム          | 型    | 説明        |
| ------------ | ---- | --------- |
| Points       | int  | ユーザーポイント  |
| AdFreeUntil  | datetime | 広告非表示期限  |
| RegistrationDate | datetime | ユーザー登録日 |

#### 2.2.2 DangerSpots

| カラム         | 型             | NULL | 説明     |
| ----------- | ------------- | ---- | ------ |
| Status      | int           | No   | 0:Open, 1:Confirmed, 2:Resolved |
| CreatedAt   | datetime      | No   | 投稿日時 |
| UpdatedAt   | datetime      | Yes  | 更新日時 |
