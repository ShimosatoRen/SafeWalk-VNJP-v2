# SafeWalk VNJP 要件定義書

| 項目      | 内容                           |
| ------- | ---------------------------- |
| プロジェクト名 | SafeWalk VNJP（歩行者危険情報共有システム） |
| バージョン   | 1.0                    |
| 作成日     | 2026-06-04                   |
| ステータス   | 運用中                        |

> 本書は、ベトナムにおける歩行者の安全性向上を目的とした危険情報共有システムの要件を整理したものである。

---

## 1. 背景・目的

### 1.1 背景
ベトナムではバイク交通量が非常に多く、歩道の未整備や信号機不足、雨季の冠水などにより歩行者が危険にさらされる場面が多い。個人の経験に依存している危険情報を共有し、安全な移動を支援する。

### 1.2 目的
* 歩行者が危険と感じた場所を記録・共有できるようにする
* 危険地点を地図上で可視化する
* ユーザーの貢献（投稿）をポイントとして可視化する
* 広告非表示などの特典を提供し、継続的な利用を促す

---

## 2. ターゲットユーザー

| 区分      | 想定ユーザー | ニーズ           |
| ------- | ------ | ------------- |
| 投稿者・閲覧者 | 地域住民   | 危険地点の共有・確認    |
| 投稿者・閲覧者 | 学生     | フィールドワーク結果の記録 |
| 投稿者・閲覧者 | 観光客    | 危険地点の事前確認     |

---

## 3. 機能要件

### 3.1 機能一覧

| ID   | 機能名          | 概要                   | 認証     |
| ---- | ------------ | -------------------- | ------ |
| F-01 | ユーザー登録       | メール・パスワード・表示名を登録     | 不要     |
| F-02 | ログイン / ログアウト | Cookie認証でログイン状態を保持   | 不要 / 要 |
| F-03 | 危険地点一覧       | 登録された危険地点を一覧表示       | 要      |
| F-04 | 危険地点詳細       | 危険内容・写真・位置情報を表示      | 要      |
| F-05 | 危険地点投稿       | 危険情報・カテゴリ・位置情報・写真を登録 | 要      |
| F-06 | 危険地点編集       | 投稿者が投稿内容を編集          | 要      |
| F-07 | 危険地点削除       | 投稿者が投稿内容を削除          | 要      |
| F-08 | 地図表示         | 危険地点を地図上に表示          | 要      |
| F-09 | ユーザー情報表示     | ポイント・広告非表示状態を表示      | 要      |

### 3.2 ユーザー特典・ゲーミフィケーション

* **ポイントシステム**: 投稿や貢献に応じてポイントを付与する。
* **広告非表示機能**: ポイントなどで広告非表示ステータスを獲得可能。
