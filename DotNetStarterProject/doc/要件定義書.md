# SafeWalk VNJP 要件定義書（ドラフト）

| 項目      | 内容                           |
| ------- | ---------------------------- |
| プロジェクト名 | SafeWalk VNJP（歩行者危険情報共有システム） |
| バージョン   | 0.1（ドラフト）                    |
| 作成日     | 2026-05-28                   |
| ステータス   | レビュー前                        |

> 本書は、ベトナムにおける歩行者の安全性向上を目的とした危険情報共有システムの要件を整理したドラフトである。

---

## 1. 背景・目的

### 1.1 背景

ベトナムではバイク交通量が非常に多く、歩道の未整備や信号機不足、雨季の冠水などにより歩行者が危険にさらされる場面が多い。

また、危険箇所に関する情報は個人の経験に依存しており、地域住民や観光客が事前に危険を把握することが難しい。

そのため、危険箇所を共有し、誰でも確認できる仕組みが求められている。

### 1.2 目的

* 歩行者が危険と感じた場所を記録・共有できるようにする
* 危険地点を地図上で可視化する
* 地域住民や観光客の安全な移動を支援する
* フィールドワークを通じてベトナムの歩行環境を調査する

---

## 2. ターゲットユーザー

| 区分      | 想定ユーザー | ニーズ           |
| ------- | ------ | ------------- |
| 投稿者・閲覧者 | 地域住民   | 危険地点の共有・確認    |
| 投稿者・閲覧者 | 学生     | フィールドワーク結果の記録 |
| 投稿者・閲覧者 | 観光客    | 危険地点の事前確認     |
| 閲覧者     | 行政関係者  | 地域課題の把握       |

## 3. 機能要件

### 3.1 機能一覧

| ID   | 機能名          | 概要                   | 認証     |
| ---- | ------------ | -------------------- | ------ |
| F-01 | ユーザー登録       | メール・パスワード・表示名を登録     | 不要     |
| F-02 | ログイン / ログアウト | Cookie認証でログイン状態を保持   | 不要 / 要 |
| F-03 | 危険地点一覧       | 登録された危険地点を一覧表示       | 要      |
| F-04 | 危険地点詳細       | 危険内容・写真・位置情報を表示      | 要      |
| F-05 | 危険地点投稿       | 危険情報・カテゴリ・位置情報・写真を登録 | 要      |
| F-06 | 危険地点編集       | 投稿者が投稿内容を編集          | 要      |
| F-07 | 危険地点削除       | 投稿者が投稿内容を削除          | 要      |
| F-08 | 地図表示         | 危険地点を地図上に表示          | 要      |
| F-09 | カテゴリ絞り込み     | カテゴリごとに一覧を絞り込み       | 要      |

### 3.2 危険カテゴリ

| カテゴリ     | 内容               |
| -------- | ---------------- |
| 横断困難     | 横断歩道や信号がなく危険     |
| 歩道未整備    | 歩道がなく歩行者が車道を利用する |
| バイク交通量過多 | バイクの通行量が非常に多い    |
| 冠水エリア    | 雨季に道路が冠水する       |
| 夜間危険     | 街灯不足などにより夜間が危険   |
| 工事中      | 工事による通行制限や危険がある  |
| 信号機なし    | 交通量が多いが信号機がない    |

### 3.3 危険レベル

| レベル | 内容     |
| --- | ------ |
| 1   | 軽微     |
| 2   | 注意     |
| 3   | 危険     |
| 4   | 非常に危険  |
| 5   | 通行回避推奨 |

### 3.4 権限ルール

* 閲覧：ログインユーザー全員可能
* 投稿：ログインユーザー全員可能
* 編集：投稿者本人のみ可能
* 削除：投稿者本人のみ可能

### 3.5 スコープ外（v0.1では実装しない）

* AIによる危険判定
* リアルタイム位置共有
* 通知機能
* コメント機能
* いいね機能
* モバイルアプリ化
* 多言語対応

### 3.6 入力チェック
* 危険地点投稿・編集
* 項目	必須	制約
* タイトル	○	100文字以内
* 危険内容	○	1000文字以内
* カテゴリ	○	指定カテゴリから選択
* 危険レベル	○	1～5
* 緯度	○	-90 ～ 90
* 経度	○	-180 ～ 180
* 写真	×	JPG / PNG、最大5MB

### 3.7 データ管理方針
* 投稿データ
* 投稿者情報を保持する
* 投稿者本人のみ編集可能
* 投稿者本人のみ削除可能
* 画像データ
* 画像はサーバー内の uploads フォルダへ保存する
* 同名ファイルによる上書きを防ぐため一意のファイル名を生成する
