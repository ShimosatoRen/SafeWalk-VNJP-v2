# SafeWalk VNJP 要件定義書

| 項目      | 内容                           |
| ------- | ---------------------------- |
| プロジェクト名 | SafeWalk VNJP（歩行者危険情報共有システム） |
| バージョン   | 1.1                    |
| 作成日     | 2026-06-09                   |
| ステータス   | 運用中                        |

> 本書は、ベトナムにおける歩行者の安全性向上を目的とした危険情報共有システムの要件を整理したものである。

---

## 1. 背景・目的

### 1.1 背景
ベトナムではバイク交通量が非常に多く、歩道の未整備や信号機不足、雨季の冠水などにより歩行者が危険にさらされる場面が多い。個人の経験に依存している危険情報を共有し、安全な移動を支援する。

### 1.2 目的
* 歩行者が危険と感じた場所を記録・共有できるようにする
* 危険地点を地図上で可視化する
* 危険地点の状態（未確認、確認済、解決済）を管理する
* ユーザーの貢献（投稿）をポイントとして可視化する
* 広告非表示などの特典を提供し、継続的な利用を促す
* 管理者によるユーザーおよび投稿情報の健全な維持管理を行う

| 区分      | 想定ユーザー | ニーズ           |
| ------- | ------ | ------------- |
| 一般ユーザー | 地域住民   | 危険地点の共有・確認    |

## 3. 機能要件

### 3.1 一般ユーザー向け機能

| ID   | 機能名          | 概要                   | 認証     |
| ---- | ------------ | -------------------- | ------ |
| F-01 | ユーザー登録       | メール・パスワード・表示名を登録     | 不要     |
| F-02 | ログイン / ログアウト | Cookie認証でログイン状態を保持   | 不要 / 要 |
| F-03 | 危険地点一覧       | カテゴリ、キーワード、危険レベルでフィルタ・検索可能 | 要      |
| F-04 | 危険地点詳細       | 危険内容・写真・位置情報・ステータスを表示 | 要      |
| F-05 | 危険地点投稿       | タイトル、内容、カテゴリ（複数）、位置、写真を登録 | 要      |
| F-06 | 危険地点編集       | 投稿者が投稿内容（タイトル、内容、カテゴリ、写真）を編集 | 要      |
| F-07 | 危険地点削除       | 投稿者が自らの投稿内容を削除          | 要      |
| F-08 | 地図表示         | 危険地点を地図（Leaflet.js）上に表示。未ログインでも閲覧可 | 不要     |
| F-09 | マイページ・情報表示 | 自身の獲得ポイント、広告非表示期限、登録日を表示 | 要      |
| F-10 | 自分の投稿一覧     | 自身が投稿した危険地点を一覧表示       | 要      |
| F-11 | ステータス変更     | 投稿者が投稿のステータス（Open/Confirmed/Resolved）を変更 | 要      |

### 3.2 管理者向け機能（Admin権限必須）

| ID   | 機能名          | 概要                   | 認証     |
| ---- | ------------ | -------------------- | ------ |
| A-01 | 管理ダッシュボード   | ユーザー数、投稿数、未確認投稿数の統計表示 | 要(Admin) |
| A-02 | ユーザー管理       | ユーザー一覧表示、Admin権限付与/剥奪、ポイント調整、ユーザー削除 | 要(Admin) |
| A-03 | 投稿管理         | 全投稿の一覧表示、管理者によるステータス更新、不適切な投稿の削除 | 要(Admin) |

### 3.3 ゲーミフィケーション・付加価値

* **ポイントシステム**: 投稿ごとに10ポイントを付与。
* **危険レベル算出**: 投稿されたカテゴリの組み合わせに基づき、システムの重み付け計算により危険レベル(1-5)を自動算出。
* **重複検知（近接投稿）**: 同一地点（緯度経度近似）への投稿数を集計し、注目度として表示。
* **広告非表示特典**: 獲得ポイントに応じて広告非表示期間が付与される（将来的な拡張予定）。

## 4. 画面構成

| ID   | 画面名    | アクセスURL | 概要 |
| ---- | ------ | --- | --- |
| S-01 | トップ    | `/` | システム紹介、最新情報の提示 |
| S-02 | 地図ビュー  | `/DangerSpots/Map` | 全危険地点の視覚的確認 |
| S-03 | 危険地点一覧 | `/DangerSpots` | 検索・フィルタリング可能なリスト表示 |

| S-07 | マイページ   | `/Account/MyPage` | プロフィール、ポイント確認 |
| S-08 | 管理画面   | `/Admin` | 統計、ユーザー一覧、全投稿一覧 |
| S-09 | ヘルプ・プライバシー | `/Home/Help`, `/Privacy` | 利用案内、個人情報保護方針 |
