# ASP.NET Identity 認証実装手順書

この手順書は `DotNetStarterProject` に実装済みの認証機能を基準にしています。
Migration の作成・DB 反映手順は [マイグレーション手順書.MD](./マイグレーション手順書.MD) を参照してください。

## 前提

- ASP.NET Core MVC アプリケーション
- Target Framework: `net10.0`
- DB: PostgreSQL
- 接続文字列名: `DefaultConnection`
- 認証方式: ASP.NET Identity + Cookie 認証

## 1. 必要パッケージ

`DotNetStarterProject.csproj` に以下を追加します。

```xml
<PackageReference Include="Microsoft.AspNetCore.Identity.EntityFrameworkCore" Version="10.0.8" />
<PackageReference Include="Microsoft.EntityFrameworkCore.Design" Version="10.0.8">
  <PrivateAssets>all</PrivateAssets>
  <IncludeAssets>runtime; build; native; contentfiles; analyzers; buildtransitive</IncludeAssets>
</PackageReference>
<PackageReference Include="Npgsql" Version="10.0.2" />
<PackageReference Include="Npgsql.EntityFrameworkCore.PostgreSQL" Version="10.0.1" />
```

`Microsoft.AspNetCore.Authentication.Cookies` は `Microsoft.AspNetCore.App` に含まれるため、このプロジェクトでは個別追加していません。

## 2. 接続文字列

`appsettings.json` に PostgreSQL 接続文字列を設定します。

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Port=8888;Database=sandbox;Username=postgres;Password=postgres"
  }
}
```

## 5. ViewModel

作成先: `Models/AccountViewModels.cs`

登録とログインで使用する入力モデルを作成します。

```csharp
using System.ComponentModel.DataAnnotations;

namespace DotNetStarterProject.Models;

public sealed class RegisterViewModel
{
    [Required]
    [EmailAddress]
    public string Email { get; init; } = string.Empty;

    [Required]
    [DataType(DataType.Password)]
    public string Password { get; init; } = string.Empty;
}

public sealed class LoginViewModel
{
    [Required]
    [EmailAddress]
    public string Email { get; init; } = string.Empty;

    [Required]
    [DataType(DataType.Password)]
    public string Password { get; init; } = string.Empty;

    public bool RememberMe { get; init; }
}
```

## 6. Program.cs

`Program.cs` で DbContext、Identity、Cookie 設定、認証ミドルウェアを登録します。

```csharp
using DotNetStarterProject.Data;
using DotNetStarterProject.Models;
using Microsoft.AspNetCore.Identity;
using Microsoft.EntityFrameworkCore;

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddControllersWithViews();
builder.Services.AddDbContext<ApplicationDbContext>(options =>
{
    var connectionString = builder.Configuration.GetConnectionString("DefaultConnection")
        ?? throw new InvalidOperationException("Connection string 'DefaultConnection' is not configured.");

    options.UseNpgsql(connectionString);
});

builder.Services
    .AddIdentity<ApplicationUser, IdentityRole>()
    .AddEntityFrameworkStores<ApplicationDbContext>()
    .AddDefaultTokenProviders();

builder.Services.ConfigureApplicationCookie(options =>
{
    options.LoginPath = "/Account/Login";
});

var app = builder.Build();

if (!app.Environment.IsDevelopment())
{
    app.UseExceptionHandler("/Home/Error");
}

app.UseRouting();

app.UseAuthentication();
app.UseAuthorization();

app.MapStaticAssets();

app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Home}/{action=Index}/{id?}")
    .WithStaticAssets();

app.Run();
```

`UseAuthentication()` は `UseAuthorization()` より前に配置します。

## 7. AccountController

作成先: `Controllers/AccountController.cs`

実装するアクション:

- `GET /Account/Register`
- `POST /Account/Register`
- `GET /Account/Login`
- `POST /Account/Login`
- `POST /Account/Logout`

登録成功時は `SignInManager.SignInAsync` でそのままログインします。
ログイン処理は `PasswordSignInAsync` を使用します。
POST アクションには `ValidateAntiForgeryToken` を付けます。

## 8. View

作成先:

- `Views/Account/Register.cshtml`
- `Views/Account/Login.cshtml`

どちらも Tag Helper と ViewModel を使ってフォームを作成します。

Register 画面の要素:

- Email
- Password
- 登録ボタン
- ログイン画面へのリンク

Login 画面の要素:

- Email
- Password
- RememberMe
- ログインボタン
- 登録画面へのリンク

## 9. Layout

`Views/Shared/_Layout.cshtml` のナビゲーションにログイン状態を表示します。

未ログイン時:

- Register
- Login

ログイン時:

- ユーザー名
- Logout

Logout は `POST` フォームで実行します。

## 10. 動作確認

```bash
dotnet build DotNetStarterProject/DotNetStarterProject.csproj
dotnet run --project DotNetStarterProject/DotNetStarterProject.csproj
```

確認する URL:

- `/Account/Register`
- `/Account/Login`

登録画面からユーザー登録すると、登録後にホーム画面へ遷移し、ナビゲーションにログイン中のユーザー名が表示されます。

## 元の手順書からの修正点

- 名前空間を `SampleApp` ではなく `DotNetStarterProject` に修正
- `Microsoft.AspNetCore.Authentication.Cookies` の個別追加を不要として整理
- `Microsoft.EntityFrameworkCore.Design` を追加
- `Npgsql` を EF Core プロバイダーに合わせて 10 系へ更新
- `Register` だけでなく `Login` / `Logout` も追加
- 文字列引数ではなく ViewModel を使う形に変更
- POST アクションに CSRF 対策の `ValidateAntiForgeryToken` を追加
- Migration 手順を別ドキュメントへ分離
